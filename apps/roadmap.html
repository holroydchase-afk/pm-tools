Use this board from other chats and projects

Any Claude chat, project or Claude Code session can read and update this board. Paste this page's link and ask, for example: “Add a card to my ccwatts board: write the README, owner Claude Code, Next.”

Boards live in the boards collection (document id is the board key). Cards live in cards, one flat collection, each tagged with its board:

boards/<key>  { name, goal, me, phases: ["MVP","Beta","Launch"], order }
cards/<id>    { board: "<key>", title, detail, lane: "later"|"next"|"now"|"done",
               owner, phase, size, due: "YYYY-MM-DD", tags, link,
               blocked: true|false, order: number, updated: ISO time }

“My tasks” filters on the board's me owner name. Copy the board as JSON to move it somewhere else; paste JSON into a new board to bring one in.
