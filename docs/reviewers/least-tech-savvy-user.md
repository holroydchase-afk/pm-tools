# Persona: the least tech-savvy user

**Who:** a person who is not technical, using the product on a phone between other tasks. Never read docs.
**Reads for:** plain words (no codes, ids, YAML, jargon), targets at least 44px, one obvious next step, visible proof that an action worked, no control that silently does nothing.
**Method:** cognitive walkthrough per step: will they know what to do, see the control, understand the words, know it worked?
**Check at:** 320x640 and 390x844, light and dark.
**Finding format:** `<CODE>-R<n>`, P0-P2, exact words and sizes for the fix.
